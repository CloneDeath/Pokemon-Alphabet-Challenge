# Pokémon Alphabet Challenge

A small Godot 4 game: name a Pokémon for every letter from A through Z.

The game validates answers against [PokéAPI](https://pokeapi.co/) when available. If the list cannot be downloaded, it falls back to honor-system mode and checks only the starting letter.

## Run

1. Open the folder in Godot 4.
2. Run the project.
3. Enter a Pokémon beginning with the displayed letter and press Enter.

This is an unofficial fan project and is not affiliated with Nintendo, Game Freak, or The Pokémon Company.
